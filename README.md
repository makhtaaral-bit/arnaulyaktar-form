# Арнаулы әлеуметтік қызметтер — құжат нысандары

4 нысанды (2 өтініш + 2 медициналық карта) толтыруға, ортақ өрістерді автоматты
көшіруге және әр нысанды Word (.docx) форматында жүктеуге арналған клиенттік
қосымша. Бэкенд жоқ — барлық деректер тек пайдаланушының браузерінде қалады.

## Жергілікті іске қосу

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Нәтиже `dist/` қалтасында пайда болады — оны кез келген статикалық хостинг
(Vercel, Netlify және т.б.) арқылы жариялауға болады.

## GitHub Desktop + Vercel арқылы жариялау

1. GitHub Desktop-та **File → Add Local Repository** → осы қалтаны таңдаңыз.
2. **Publish repository** — жаңа репозиторийге (мысалы,
   `newsandletters224-maker/arnaulyaktar-form`) жариялаңыз.
3. [vercel.com](https://vercel.com) → **Add New → Project** → осы GitHub
   репозиторийін импорттаңыз. Vercel фреймворкты (Vite) автоматты анықтайды —
   қосымша баптау қажет емес.
4. Деплой аяқталған соң, жобаның **Settings → Domains** бөлімінде керекті
   субдомениді қосыңыз (мысалы, `jartylay.jumis-maktaaral.kz`) және Vercel
   берген CNAME жазбасын Gohost.kz-тағы DNS аймағына қосыңыз.

## Ескерту

Бұл қосымша `vivid-acre-moss-crane.grok.me` сайтындағы көрінетін мазмұн мен
құрылым негізінде қайта құрылды (тегін/бос .docx ресми үлгісі негізінде емес).
Іске қосу алдында әр нысанды мұқият тексеріп, ресми құжат талаптарына сәйкес
екеніне көз жеткізіңіз.
